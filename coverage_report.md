## Structured sender/recipient fields — PLAN CORRECTION

The project plan (PLAN.md §2.1) claims the catalogue has **no** structured
sender/addressee fields and budgets Phase 1 around parsing address formulae.
**This is wrong for the raw `catalogue.json`** (the plan checked the pager
display config only):

- `ancient_author` (sender) present and non-missing: **309/379** (111 distinct raw values)
- `recipient` present and non-missing: **333/379** (32 distinct raw values)

Consequence: the Phase 1 header parser is demoted from critical-path to a
validation/backfill tool. Entity resolution across raw value variants is
still required (registry keyed on these strings + lemma IDs).
